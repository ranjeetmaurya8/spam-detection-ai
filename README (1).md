
# Project Title

AI Spam Message Detector

An AI-powered spam detection web application built using
Python, Machine Learning and Streamlit.


## Run Locally

Clone the project

```bash
  git clone https://spam-detection-ai-qfrqzjsdfyxqc8umfyjcb4.streamlit.app/
```

Go to the project directory

```bash
  cd my-project
```

Install dependencies

```bash
  npm install
```

Start the server

```bash
  npm run start
```

## Features

 Detects spam and legitimate messages
- Machine Learning based prediction
- Simple and attractive UI
- Real-time prediction
- Deployed using Streamlit


## Tech Stack

- Python
- Streamlit
- Scikit-learn
- TF-IDF
- Multinomial Naive Bayes
